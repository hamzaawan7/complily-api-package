# Unified API Integrations for Laravel

A reusable Laravel package for authenticating with and making requests to multiple third-party APIs through one integration layer.

## Stack

- PHP
- Laravel 8, 9, and 10
- Guzzle
- PSR-4 autoloading

## Installation

```bash
composer require communication-marketplaces/multi-api-integrations
```

Publish the package configuration:

```bash
php artisan vendor:publish --provider="CommunicationMarketplaces\\UnifiedApiIntegrations\\Providers\\IntegrationServiceProvider" --tag="config"
```
